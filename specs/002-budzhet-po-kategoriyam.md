# Бюджет по категориям

## Для кого и зачем

Для человека, который ведёт личный учёт расходов и хочет заранее ограничить траты по категориям, видеть состояние бюджета текущего месяца и вовремя замечать перерасход.

## Что должно быть

- На странице есть раздел «Бюджет месяца» для категорий «Еда», «Транспорт», «Дом» и «Другое».
- Для каждой категории можно задать месячный лимит в тенге и сохранить его.
- Сохранённые лимиты применяются к каждому календарному месяцу, пока пользователь их не изменит.
- Лимиты хранятся в `localStorage` отдельно от списка трат и сохраняются после F5.
- Общий бюджет месяца равен сумме лимитов всех категорий.
- Для каждой категории показываются:
  - лимит на месяц;
  - сумма трат за текущий календарный месяц;
  - оставшаяся сумма.
- В расчёт категории входят только траты этой категории с датой в текущем календарном месяце.
- Пока траты не превысили лимит, остаток равен разнице между лимитом и тратами.
- Если траты превысили лимит, вместо отрицательного остатка показываются заметная подпись «Перерасход» и сумма превышения.
- После добавления новой траты показатели категории и общий расход месяца обновляются сразу.
- Пустой, нулевой, отрицательный или нечисловой лимит не сохраняется; рядом с полем показывается короткая ошибка.

## Примеры

- Задать лимиты: «Еда» — `10 000`, «Транспорт» — `5 000`, «Дом» — `20 000`, «Другое» — `3 000` → общий бюджет месяца равен `38 000,00 ₸`.
- При лимите «Еда» `10 000` и тратах текущего месяца на `9 900` и `1 000` в этой категории показываются: потрачено `10 900,00 ₸`, «Перерасход 900,00 ₸».
- Трата «Еда» на `2 000` с датой прошлого месяца не меняет показатели текущего месяца.
- После F5 лимиты и рассчитанные по сохранённым тратам значения остаются прежними.

## Ограничения

- Используются только HTML, CSS и JavaScript без библиотек и внешних ресурсов.
- Данные хранятся только в браузере через `localStorage` и никуда не отправляются.
- Существующие траты и ключ их хранения остаются совместимыми с новой функцией.
- Интерфейс и сообщения об ошибках — на русском языке.
- Денежные суммы отображаются с двумя знаками после запятой, пробелами между разрядами и знаком `₸`.
- Для ввода лимита поддерживаются целые суммы и суммы с двумя знаками после запятой.
- Кнопки и поля имеют высоту не меньше 44 px.
- На экране шириной 375 px блок бюджета не создаёт горизонтальную прокрутку, а все значения остаются читаемыми.

## Готово, когда

- Можно задать и сохранить корректный лимит для каждой из четырёх категорий.
- Общий бюджет правильно складывается из лимитов категорий.
- Для каждой категории правильно рассчитаны траты и остаток за текущий календарный месяц.
- При превышении лимита видны предупреждение и точная сумма перерасхода.
- Траты за другие месяцы не влияют на показатели текущего месяца.
- Новая трата сразу меняет показатели соответствующей категории.
- После F5 лимиты и рассчитанные значения сохраняются.
- Некорректные лимиты не сохраняются, а пользователю показывается понятная ошибка.
- На ширине 375 px нет горизонтальной прокрутки, поля и кнопки доступны.

- [ ] Шаг 2. Расходы, остатки и перерасход. В разделе бюджета для каждой категории появятся суммы «Потрачено» и «Осталось», а при превышении лимита — предупреждение с суммой перерасхода. Проверка: добавить траты `9900` и `1000` в одну категорию с лимитом `10000`; убедиться, что потрачено `10 900,00 ₸` и показан перерасход `900,00 ₸`; добавить трату прошлым месяцем и убедиться, что расчёт не изменился.
- [ ] Шаг 3. Проверка мобильного вида и завершение. Блок бюджета будет окончательно адаптирован для ширины 375 px, а `README.md` дополнен описанием функции и полной ручной проверкой. Проверка: открыть страницу при ширине 375 px и убедиться, что нет горизонтальной прокрутки; проверить доступность всех полей и кнопок; выполнить проверку из обновлённого `README.md`.
